# Assignment 3 Self-Reflection

What surprised me most was how weakly technological novelty predicted business-model disruption. The same LLM agent was a modest productivity tool for the marketing agency, but it threatened the logistics company's manual freight-audit function - and the value tied to that function - far more than its "newness" suggested. The bank case sharpened this further because the disruption risk came less from adopting too early than from failing to respond if competitors automate servicing first. Those contrasts changed my thinking from "How new is this technology?" to "Which product, process, cost structure, or intermediary loses value if it works?" Now, when someone calls a technology "disruptive," I would ask disruptive to whom and to what part of the business model, look for evidence of what it would displace as well as create, and test the strongest case that the incumbent model survives before accepting the label.
